# 과제 02: 이진트리 프로그램

각 구현은 헤더, 구현 파일, 실행 파일의 3개 파일로 구성되어 있습니다.

## 입력 규칙

- 노드 이름은 한 글자이며 서로 달라야 합니다.
- 기본 형식: `부모(왼쪽,오른쪽)`
- 빈 자식은 공백으로 입력할 수 있습니다.
  - `a( ,b)`: 왼쪽 자식 없음
  - `a(b, )`: 오른쪽 자식 없음
- 예시: `a(b(d,e),c( ,f))`

## 컴파일

### 배열 방식

```sh
cd array_tree
gcc -std=c11 -Wall -Wextra -pedantic main.c array_tree.c -o array_tree
./array_tree
```

### 연결 자료구조 방식

```sh
cd linked_tree
gcc -std=c11 -Wall -Wextra -pedantic main.c linked_tree.c -o linked_tree
./linked_tree
```

높이는 루트 노드를 1로 계산합니다. 편향 이진트리는 모든 비단말 노드가
같은 방향의 자식 하나만 갖는 경우로 정의했습니다.

## 3-[1] 배열과 연결 자료구조의 메모리 사용량 비교

동일하게 7개 노드를 가진 세 종류의 트리를 64비트 환경에서 실행하여
측정했습니다. 프로그램이 출력하는 값은 트리 관리 구조체까지 포함한
실제 할당 공간입니다.

| 트리 형태 | 시험 입력 | 배열 방식 | 연결 방식 |
|---|---|---:|---:|
| 일반 이진트리 | `a(b(d(,g),e),c(,f))` | 152 bytes | 176 bytes |
| 완전·포화 이진트리 | `a(b(d,e),c(f,g))` | 88 bytes | 176 bytes |
| 오른쪽 편향 이진트리 | `a(,b(,c(,d(,e(,f(,g))))))` | 1048 bytes | 176 bytes |

배열 노드 하나는 데이터와 사용 여부를 저장하며, 연결 노드 하나는
데이터와 왼쪽·오른쪽 포인터를 저장합니다. 따라서 완전 이진트리처럼
인덱스가 빈틈없이 채워진 경우에는 별도의 포인터가 필요 없는 배열
방식이 더 적은 메모리를 사용합니다.

일반 이진트리에서는 비어 있는 배열 인덱스 때문에 배열의 장점이
줄어듭니다. 특히 편향 이진트리는 깊이가 증가할 때 마지막 인덱스가
지수적으로 증가합니다. 7개 노드인 오른쪽 편향 트리의 인덱스는
`1, 3, 7, 15, 31, 63, 127`이므로 실제 노드는 7개뿐이어도 큰 배열이
필요합니다. 반면 연결 방식은 트리 형태와 관계없이 실제 노드에
대해서만 메모리를 할당하므로 사용량이 노드 수에 비례합니다.

측정값은 포인터 크기, 구조체 정렬 방식 및 배열 확장 정책에 따라
환경별로 조금 달라질 수 있지만, 트리 형태에 따른 경향은 같습니다.

## 3-[2] 부모·자식·형제 노드 탐색 및 효율 비교

두 프로그램의 마지막 입력에서 찾을 노드 한 글자를 입력하면 부모,
왼쪽 자식, 오른쪽 자식, 형제 노드가 출력됩니다. 노드 값은 서로
중복되지 않는다고 가정합니다.

| 작업 | 배열 방식 | 연결 방식 |
|---|---:|---:|
| 인덱스를 아는 상태에서 부모 계산 | O(1), `i / 2` | O(N), 루트부터 탐색 |
| 자식 접근 | O(1), `2i`, `2i + 1` | O(1), `left`, `right` |
| 형제 계산 | O(1), `i - 1` 또는 `i + 1` | O(N), 부모 탐색 필요 |
| 값으로 대상 노드 찾기 | O(N) | O(N) |

배열 방식은 노드의 인덱스를 알면 부모, 자식, 형제의 위치를 수식으로
즉시 계산할 수 있습니다. 기본 연결 이진트리는 자식 포인터만 가지고
있으므로 자식 접근은 빠르지만 부모와 형제를 찾으려면 루트부터
탐색해야 합니다.

이 프로그램처럼 사용자가 노드의 인덱스가 아니라 값을 입력하면
양쪽 구현 모두 먼저 대상 노드를 찾아야 하므로 전체 조회 시간은
최악의 경우 O(N)입니다. 그러나 대상 위치를 이미 알고 있거나 관계
탐색이 빈번한 작업에서는 배열 방식이 더 효율적입니다. 반대로
연결 노드에 부모 포인터를 추가하면 부모와 형제 접근도 O(1)로
개선할 수 있지만 노드마다 포인터 하나만큼 메모리가 더 필요합니다.
